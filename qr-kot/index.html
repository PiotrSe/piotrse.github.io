How it works

From idea to finished code in four steps

Creating a graphic with a custom background is optional — you can generate or scan an ordinary QR code just as quickly.

  1. 1

    Create or scan a QR code

    Generate a code from text or a URL, or read an existing code.

  2. 2

    Choose your own background

    If you want to create a graphic, take a photo or pick an image from your gallery.

  3. 3

    Move and resize the code

    Position the QR code on the photo and adjust its size.

  4. 4

    Share the result

    Save the finished graphic and share it or use it wherever you like.

You do not need to create a graphic to use QR Kot — the generator and scanner work on their own.
